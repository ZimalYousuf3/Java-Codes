# ☕ Java-Codes

A collection of beginner-friendly Java programs built as part of my BSCS journey. These projects cover core Java concepts including OOP, GUI development with Java Swing, and basic logic building.

---

## 📁 Files in This Repository

| File | Description |
|------|-------------|
| `HelloWorld.java` | Classic first Java program — prints "Hello World!" |
| `Student.java` | A simple class with name and age attributes using a constructor |
| `Input_Class.java` | Takes user input using `Scanner` for name and age |
| `SimpleCalc.java` | A basic GUI calculator that adds two numbers using Java Swing |
| `GradeCalculator.java` | GUI app that calculates CGPA and grade from 6 subject marks |
| `CurrencyConverter.java` | GUI app that converts Pakistani Rupees to USD and GBP |

---

## 🛠️ Technologies Used

- **Language:** Java
- **GUI Library:** Java Swing
- **IDE:** Eclipse / VS Code

---

## 🚀 How to Run

1. Make sure you have **Java JDK** installed on your system.
2. Clone this repository:
```bash
   git clone https://github.com/ZimalYousuf3/Java-Codes.git
```
3. Navigate to the project folder and compile any file:
```bash
   javac FileName.java
   java FileName
```
